# DOKO — Restaurant Showcase

واجهة عرض تجريبية لنظام مطعم دوكو.

## التشغيل محلياً
```bash
npm install
npm run dev
```

## البناء
```bash
npm run build
```

## النشر على Vercel
تمت إضافة `vercel.json` ومسار Express Serverless Function تحت `api/` حتى تتعامل واجهة العرض مع مسارات `/api/*` على Vercel.

**تنبيه مهم:** هذا المشروع مخصص للعرض التجريبي فقط، وليس لتشغيل مطعم فعلي أو حفظ بيانات تشغيلية. التخزين الحالي يعتمد على ملف JSON محلي، وبيئة Vercel Serverless لا تضمن استمرارية الكتابة على ملفات المشروع أو مشاركة الحالة بين النسخ؛ كما أن بث SSE لا يناسب وظائف Serverless طويلة العمر. يلزم ربط قاعدة بيانات وخدمة تحديثات مناسبة قبل أي استخدام تشغيلي حقيقي.
